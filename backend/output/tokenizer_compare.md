# BM25 中文分词对比：jieba vs 字符滑动窗口

- 评测范围：任务 1 评测集中的中文查询子集（67 条），仅 BM25 稀疏检索一路
- 知识库规模：385 chunks
- 指标：top-k 命中率 = 期望关键词出现在前 k 个结果中的比例

| 指标 | 字符滑动窗口 | jieba + 停用词 |
|---|---|---|
| top-1 命中率 | 86.57% | 83.58% |
| top-3 命中率 | 89.55% | 86.57% |
| top-5 命中率 | 89.55% | 86.57% |
| 词汇表规模（唯一 term） | 1347 | 890 |

> 结论：在「字面精确匹配」的 BM25 中文命中率上，字符 bigram 略优于 jieba（top-5 89.55% vs 86.57%），因为 n-gram 对查询/文档分词不一致更鲁棒；jieba 的优势是词级语义切分 + 停用词过滤后索引更精简（词汇表更小），二者命中率差距在个位数，且混合检索的向量一路不受分词影响。
